Política de Privacidade — SheetsBot

Última atualização: 1 de outubro de 2026.

Quem usa

O SheetsBot é uma automação pessoal usada somente pelo seu autor, Alan Moura, na própria conta Google.

Dados acessados

Com o escopo gmail.readonly, o aplicativo busca apenas os e-mails de código de verificação enviados pela plataforma de ensino e extrai o código numérico necessário para o login. Nenhum e-mail é alterado, enviado ou apagado.

Armazenamento e compartilhamento

  • Os dados são processados apenas no computador do autor.
  • O conteúdo dos e-mails não é armazenado. Somente o token de autorização fica salvo localmente.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
